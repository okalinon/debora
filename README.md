# Debora

*English:* [README.en.md](README.en.md) · [Changelog](CHANGELOG.md)

Утиліта для оптимізації, деблоату та обслуговування Windows 10/11 з графічним інтерфейсом.
Ідейно схожа на [WinUtil](https://winutil.christitus.com/), але має власну архітектуру й відрізняється в ключовому:

- **Знає залізо.** Визначає HDD/SSD, обсяг RAM, процесор, батарею й версію Windows і пропонує профіль саме під цей ПК (наприклад, «Слабкий ПК: HDD + 4 ГБ»).
- **Чесний відкат.** Перед кожною зміною записує *попередній* стан (значення реєстру, тип запуску служби, стан завдання). Відкат повертає саме те, що було, а не «значення за замовчуванням».
- **Показує поточний стан.** Кожен твік уміє перевірити, чи він уже застосований: в інтерфейсі видно ✓ / ✗ / частково.
- **Попередній перегляд.** Режим «що буде змінено» показує кожен ключ реєстру, службу й застосунок до натискання «Застосувати».
- **Українська за замовчуванням**, з англійською локалізацією.

Статус: **1.0.0** (перший реліз) — вікно в стилі «Фокус» (рейка зі значками, згруповані списки, кільце оцінки стану) з 12 вкладками, де кожна функція є лише в одному місці (Огляд, Налаштування, Деблоат, З нуля, Драйвери, Програми, Видалення, Автозавантаження, Обслуговування, Перевстановлення, Журнал змін), світла й темна тема, текстове меню й CLI. 184 перевірки сканера (паралельно, з оцінкою й HTML-звітом; знахідки про зайняте місце розгортаються в перелік файлів і папок з кнопкою «Відкрити в Провіднику») з поясненням причин: розшифровка синіх екранів, модуль, у якому падають програми, хто сповільнює завантаження, індекс стабільності; у кожній знахідці — кнопка «Виправити» (лише ця знахідка, з попереднім переглядом змін) або «Як виправити» (покрокова інструкція), а «Сканувати й виправити все» виконує весь план; панель «Зараз виконується» з кроком, шкалою, таймером і оцінкою часу за фактом минулого разу, черга задач і кнопка «Зупинити»; будь-яку знахідку можна прийняти й приховати (знахідки з подій повертаються з новим випадком); майстер «Налаштування з нуля» — один прохід після чистої Windows (драйвери, деблоат, профіль налаштувань, програми, оновлення, перевірка) з профілем, який зберігається у файл, переноситься на інший ПК і виконується з флешки перевстановлення; 55 твіків, 6 профілів, журнал і точний відкат; драйвери з інтернету (Microsoft Update Catalog + Windows Update, утиліти Dell/Lenovo/HP); 567 програм з іконками (winget і релізи GitHub, зокрема відкриті аналоги Adobe й Office від ArtCraft), 9 наборів; видалення програм з розміром, датою й прибиранням залишків (папки — у Кошик, реєстр — з резервною копією); поради для автозавантаження; стан дисків (температура, знос, помилки SMART); автообслуговування за розкладом; флешка для перевстановлення Windows без запитань і з драйверами; пакет діагностики. Ранній прототип з вікном — [`prototype/windows-optimize.ps1`](prototype/windows-optimize.ps1).

## Як користуватися (готова збірка)

1. Завантажте `Debora-<версія>.zip` з розділу [Releases](../../releases) і розпакуйте всю папку.
2. Двічі клацніть **Debora.exe** → підтвердіть права адміністратора → відкриється вікно з 12 вкладками.
   Без прав адміністратора Debora лише показує стан ПК.
3. SmartScreen може написати «Windows захистила ваш ПК» (програма ще без цифрового підпису): «Додаткові відомості» → «Виконати все одно». Контрольні суми — у `SHA256SUMS`.
4. Запасний запуск — `run.bat`, текстове меню — `run-menu.bat`, команди — `Debora.exe -Help`. Debora оновлюється сама з Releases (перевірка раз на добу, архів перевіряється за SHA-256).

Звіти зберігаються в папці `Звіти` поруч із програмою; журнал змін і точки відновлення — у `%ProgramData%\Debloater9`. Що нового — [CHANGELOG.md](CHANGELOG.md).

## Швидкий старт (розробка)

```powershell
# Сканування: оцінка стану, проблеми, чекліст «що робити»; HTML-звіт
.\src\Main.ps1 -Scan -Report .\report.html

# Чекліст: автоматичні галочки, виконання автоматичних кроків, ручний крок позначити виконаним
.\src\Main.ps1 -Checklist
.\src\Main.ps1 -Checklist -Run All -Yes
.\src\Main.ps1 -Checklist -Done 1

# Відомості про систему й рекомендований профіль
.\src\Main.ps1

# Каталог твіків і їхній поточний стан
.\src\Main.ps1 -ListTweaks

# Що зміниться (нічого не змінює)
.\src\Main.ps1 -Preset Recommended -WhatIf

# Застосувати (PowerShell від імені адміністратора) і відкотити
.\src\Main.ps1 -Preset WeakPC -Yes
.\src\Main.ps1 -ListSessions
.\src\Main.ps1 -Undo <id сесії> -Yes

# Тести (Pester 5+) і збирання dist\Debora.ps1
Invoke-Pester .\tests
.\build\Compile.ps1 -Version 0.1.0
```

Якщо PowerShell блокує запуск скриптів: `powershell -ExecutionPolicy Bypass -File .\src\Main.ps1 ...`

Інтеграційні тести, що змінюють служби й завдання, запускаються лише на тестовій ВМ від адміністратора: `$env:D9_INTEGRATION = '1'; Invoke-Pester .\tests`.

## Коротко про технічні рішення

- **PowerShell 5.1 + WPF (XAML)** — працює на будь-якій Windows 10/11 без встановлення .NET чи інших залежностей ([ADR-001](docs/adr/ADR-001-stack.md)).
- **Твіки описані даними (JSON), а не кодом** — додати твік = додати запис у `config/tweaks.json` ([ADR-002](docs/adr/ADR-002-declarative-tweaks.md)).
- **Відкат через знімок стану** перед зміною ([ADR-003](docs/adr/ADR-003-snapshot-undo.md)).
- **Модульний код, один файл на виході** — `build/Compile.ps1` збирає `Debora.ps1` для розповсюдження.
