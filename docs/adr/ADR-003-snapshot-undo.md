# ADR-003: Відкат через знімок попереднього стану

**Статус:** прийнято · **Дата:** 2026-10-10

## Контекст
WinUtil відкочує твік, записуючи «значення за замовчуванням». Але на конкретному ПК значення могло бути іншим (змінене виробником, політикою, користувачем) — тоді «відкат» створює новий, ніким не бажаний стан.

## Рішення
Перед кожною дією виконавець зберігає `before` (поточне значення, тип запуску, стан завдання; «не існувало» — теж стан). Відкат повертає `before`. Якщо на момент відкату стан ≠ `after`, запис пропускається з попередженням.

## Наслідки
- Відкат точний і безпечний щодо чужих змін.
- Журнали сесій зберігаються в `%ProgramData%\Debora\sessions` — їх треба не губити (експорт, очищення старих за згодою).
- Для `appx` знімок — лише перелік пакетів; повернення через winget/Store може бути неможливим для частини пакетів. Це прямо показується користувачу в preview.
- Точка відновлення лишається додатковим, а не основним механізмом.
