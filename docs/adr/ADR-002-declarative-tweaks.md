# ADR-002: Твіки як дані (JSON), а не код

**Статус:** прийнято · **Дата:** 2026-10-10

## Контекст
У прототипі кожен твік — scriptblock. Його неможливо показати в preview, перевірити стан чи автоматично відкотити: код робить що завгодно.

## Рішення
Твік описується в `config/tweaks.json` списком типізованих дій (`registry`, `service`, `appx`, `scheduledTask`, `powercfg`, `winget`). Довільний код — лише тип `command` з обов'язковим `undoRun` і ручним рев'ю.

## Наслідки
- Preview, перевірка стану й відкат працюють для всіх твіків однаково, без коду в самому твіку.
- Каталог можна валідувати JSON Schema і тестувати автоматично.
- Контриб'ютору не треба знати PowerShell, щоб додати твік з реєстру чи служби.
- Складні сценарії (OneDrive з пошуком інсталятора) потребують `command` або нового типу дії — нові типи додаємо, коли сценарій повторюється.
