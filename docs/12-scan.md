# 12. Сканер стану системи

Одна кнопка «Сканувати» на будь-якому ПК: за 20–40 секунд утиліта дає **оцінку стану Windows** і список конкретних проблем, кожна — з поясненням і кнопкою «Виправити». Повторне сканування після виправлень показує, що покращилось.

## Чекліст «що робити»

Після сканування (систему + [драйвери](13-driver-manager.md)) утиліта складає **один упорядкований чекліст** — покрокову інструкцію: що зробити, що завантажити і звідки, що встановити, в якому порядку. Пункти відмічаються **автоматично**: після кожної дії утиліта перевіряє результат і ставить галочку сама.

```
┌ Чекліст: Acer Aspire ES1-522 · 9 кроків · ~25 хв ───────────── 3 / 9 ✔ ┐
│                                                                        │
│ ✔ 1. Створити точку відновлення                          [зроблено]    │
│ ✔ 2. Драйвер Wi-Fi Qualcomm QCA9377 — щоб з'явився інтернет            │
│ ✔ 3. Драйвер ENE Serial IO                                             │
│ ☐ 4. Драйвер тачпада ELAN 13.6.2.2                                     │
│      Чому: тачпад працює як проста миша, без жестів                    │
│      Де взяти: сайт Acer, 7 МБ   [ Завантажити ]  [ Встановити ]       │
│      ⓘ Після кроку 3 — інакше не встановиться                          │
│ ☐ 5. Драйвер звуку Realtek 6.0.1.7564 (фірмовий Acer)                  │
│      [ Завантажити ]  [ Встановити ]                                   │
│ ☐ 6. Звільнити 6,2 ГБ: тимчасові файли, кеш оновлень   [ Виконати ]    │
│ ☐ 7. Профіль «Слабкий ПК»: 26 налаштувань             [ Переглянути ]  │
│ ☐ 8. Перезавантажити комп'ютер                         [ Виконати ]    │
│ ☐ 9. Вручну: Windows 10 без оновлень безпеки → варіанти   [ Деталі ]   │
│                                                                        │
│ [ Виконати всі автоматичні кроки ]  [ Друк / PDF ]  [ Зберегти HTML ]  │
└────────────────────────────────────────────────────────────────────────┘
```

**Кожен пункт містить:**
- **що** зробити — одним реченням;
- **чому** — яку проблему вирішує (з результатів сканування);
- **де взяти** — офіційне посилання (сторінка або пряме завантаження), розмір;
- **кнопку дії** — «Завантажити», «Встановити», «Виконати», «Переглянути» — або «Вручну» з інструкцією, якщо автоматично не можна (заміна диска, батареї, рішення щодо Windows 10);
- **залежності** — «після кроку 3», «потрібен інтернет», «потрібне перезавантаження».

**Порядок складається за правилами** (`config/checklist-rules.json`):
1. Безпека даних: точка відновлення; при поганому SMART — першим пунктом «зробіть копію файлів».
2. **Мережевий драйвер** — щоб усе інше можна було завантажити.
3. Драйвери в порядку залежностей: чипсет / Serial IO → тачпад, відео, звук, решта.
4. Критичні проблеми безпеки (Захисник, брандмауер).
5. Очищення диска.
6. Твіки рекомендованого профілю.
7. Оновлення програм.
8. Перезавантаження — один раз, наприкінці (якщо потрібне хоча б одному кроку).
9. Ручні пункти й поради — окремим блоком внизу.

**Прогрес зберігається** (`%ProgramData%\Debloater9\checklists\`): можна закрити утиліту, перезавантажитись — і продовжити з того самого кроку. Повторне сканування оновлює чекліст: виконані пункти зникають, нові проблеми додаються.

**Для друку / іншого ПК:** чекліст зберігається як HTML/PDF з посиланнями — його можна відкрити на телефоні чи іншому комп'ютері й завантажити все потрібне на флешку.

## Перевірки

Рівні: ✖ **критично** — ризик втрати даних чи безпеки · ⚠ **варто виправити** — помітно гальмує або засмічує · 💡 **порада** · ℹ **відомості**.

### Безпека
| Перевірка | Джерело | Рівень |
|---|---|---|
| Версія Windows ще підтримується | збірка → таблиця дат кінця підтримки (`config/lifecycle.json`) | ✖ якщо ні |
| Захисник увімкнено, сигнатури свіжі (< 3 днів), реальний час увімкнено | `Get-MpComputerStatus` | ✖ / ⚠ |
| Два й більше антивіруси одночасно | `root\SecurityCenter2\AntiVirusProduct` | ⚠ |
| Брандмауер увімкнено для всіх профілів | `Get-NetFirewallProfile` | ✖ |
| UAC увімкнено, Secure Boot (якщо UEFI) | реєстр, `Confirm-SecureBootUEFI` | ⚠ / ℹ |
| Windows активовано | `SoftwareLicensingProduct` | ℹ (лише інформуємо) |

### Оновлення
| Перевірка | Джерело | Рівень |
|---|---|---|
| Останнє накопичувальне оновлення старше 60 днів | `Get-HotFix` / історія Windows Update | ⚠ |
| Очікує перезавантаження після оновлень | ключі `RebootRequired`, `PendingFileRenameOperations` | ⚠ |
| Пристрої без драйвера / з помилкою | [Драйвери](11-drivers.md) | ⚠ |
| Застарілі програми | `winget upgrade` (глибоке сканування) | 💡 |

### Диск
| Перевірка | Джерело | Рівень |
|---|---|---|
| Здоров'я дисків (усіх внутрішніх, флешки не оцінюються): стан Windows, прогноз відмови SMART, невиправні помилки, знос SSD, температура | `Get-D9DiskHealth`: `MSFT_PhysicalDisk.HealthStatus`, `MSFT_StorageReliabilityCounter`, `MSStorageDriver_FailurePredictStatus` | ✖ |
| Вільне місце на C: < 10% або < 15 ГБ | `Win32_LogicalDisk` | ✖ / ⚠ |
| Що можна звільнити: TEMP, кеш оновлень, кошик, `Windows.old`, кеш браузерів, дампи пам'яті | розміри папок | ⚠ якщо > 2 ГБ |
| Фрагментація HDD > 10% | `Optimize-Volume -Analyze` (глибоке) | 💡 |
| TRIM вимкнено на SSD | `fsutil behavior query DisableDeleteNotify` | ⚠ |

### Швидкодія
| Перевірка | Джерело | Рівень |
|---|---|---|
| Автозавантаження: кількість і вплив програм | `Run`-ключі, папка Startup, завдання при вході, `StartupApproved` | ⚠ якщо > 8 |
| Пам'ять: зайнято > 85% у спокої, топ-5 процесів | `Win32_OperatingSystem`, `Get-Process` | ⚠ |
| Невідповідність заліза й налаштувань (HDD + SysMain, анімації на слабкому ПК, схема «Економія» на ПК від мережі) | твіки каталогу + `SystemInfo` | ⚠ |
| Комп'ютер не перезавантажувався > 7 днів (швидкий запуск ≠ перезавантаження) | `LastBootUpTime` | 💡 |
| Сторонні «оптимізатори» та trial-антивіруси (McAfee, Norton trial, Driver Booster, тулбари) | список програм у `Uninstall` + `config/known-bloat.json` | ⚠ |

### Чистота й конфіденційність
| Перевірка | Джерело | Рівень |
|---|---|---|
| Встановлені рекламні застосунки з каталогу | стан `apps.remove-bloat` тощо | 💡 |
| Твіки рекомендованого профілю, які ще не застосовані | `Get-D9TweakState` для профілю під це залізо | 💡 |

### Стабільність
| Перевірка | Джерело | Рівень |
|---|---|---|
| Сині екрани за 30 днів з розшифровкою коду (назва, група причин, дія: драйвери / перевірка пам'яті / chkdsk / DISM+SFC); різні коди з різних груп → перевірка пам'яті | Event Log: WER-SystemErrorReporting 1001, `config/bugchecks.json` | ✖ / ⚠ |
| Аварійні вимкнення без синього екрана | Kernel-Power 41 | ⚠ |
| Збої програм з аналізом модуля: відеодрайвер → оновлення драйвера, Visual C++ → перевстановлення, .NET, багато різних програм з c0000005 → перевірка пам'яті | Application Error 1000, Application Hang 1002 | ⚠ / ℹ |
| Індекс стабільності Windows і що його знизило (сині екрани, вимкнення, збої програм, невдалі оновлення й встановлення) | `Win32_ReliabilityStabilityMetrics`, `Win32_ReliabilityRecords` | ⚠ якщо < 3, порада якщо < 5 |
| Помилки диска в журналі | Event Log: disk 7, 51, 153 | ✖ |
| Пошкодження системних файлів | `DISM /Online /Cleanup-Image /CheckHealth` (швидко), `sfc /verifyonly` (глибоке) | ⚠ |

## Архітектура

Перевірки, як і твіки, описані **даними + невеликою функцією-пробою**:

```json
{
  "id": "disk.free-space",
  "category": "disk",
  "title": { "uk": "Мало вільного місця на диску C:", "en": "Low free space on C:" },
  "probe": "Test-D9FreeSpace",
  "thresholds": { "criticalPercent": 10, "warningGB": 15 },
  "deep": false,
  "fix": { "type": "tweaks", "ids": ["cleanup.temp", "cleanup.update-cache"] }
}
```

- `config/checks.json` — метадані, пороги, як виправляти; `src/checks/*.ps1` — функції-проби.
- Проба повертає **знахідки** (`severity`, текст, виміряні значення), а не друкує їх: так один результат показують і інтерфейс, і CLI, і HTML-звіт.
- Типи виправлень (`fix.type`), від найкращого до крайнього:
  - `tweaks` — твіки з каталогу (`ids`);
  - `actions` — готові дії прямо в знахідці (`actions`: registry / service / command…, необов'язково `reboot`). Чекліст збирає їх у кроки «Виправити налаштування безпеки / системи», «Відновити роботу оновлень» і виконує через рушій, тобто з точкою відновлення, журналом і точним відкатом. У правилах `checks.json` — поле `params.fix`, у пробах — `New-D9ActionsFix`;
  - `maintenance` — разова операція з `$D9MaintenanceActions` (`src/maintenance/Repair.ps1`): `chkdskScan`, `enableRestore`, `defenderUpdate`, `defenderScan`, `wuReset`, `windowsUpdate`, `browserCache`, `wingetUpgrade`, `repairSystem`, а також `restorePoint` і `reboot`;
  - `apps` — оновити конкретні програми через winget (`ids`), наприклад вразливі версії;
  - `drivers` — вкладка «Драйвери»; `manual` — лише пояснення (залізо, BIOS, особисті файли — те, що має вирішити людина).
- Не автоматизувати зміну винятків Захисника й подібне «вимкнення захисту»: AMSI блокує такий скрипт як шкідливий (тест збірки це ловить).
- Звичайне сканування — лише швидкі перевірки, паралельно в runspace-пулі (мета ≤ 30 с на HDD). **Глибоке** — додає `winget upgrade`, пошук драйверів у Windows Update, аналіз фрагментації, `sfc /verifyonly` (кілька хвилин).
- Помилка однієї проби не зриває сканування: знахідка «не вдалося перевірити».

## Оцінка

Кожна категорія стартує зі 100: ✖ −30, ⚠ −10, 💡 −3 (не нижче 0). Загальна оцінка — зважене середнє: Безпека ×3, Диск ×2, Стабільність ×2, Оновлення ×2, Швидкодія ×1,5, Чистота ×1, Конфіденційність ×1. Будь-яке ✖ обмежує загальну оцінку 59 балами — «зелений» результат з критичною проблемою був би оманливим.

| Бали | Висновок |
|---|---|
| 85–100 | Добрий стан |
| 60–84 | Потребує уваги |
| 0–59 | Є серйозні проблеми |

## Звіт

- **HTML** — один файл без зовнішніх залежностей: оцінка, знахідки, відомості про ПК, дата. Для сервісного центру — віддати клієнту «до/після».
- **JSON** — для автоматизації й порівняння сканувань.
- Звіти зберігаються локально в `%ProgramData%\Debloater9\scans\`; утиліта нікуди їх не надсилає.

## CLI

```powershell
.\Debloater9.ps1 -Scan                          # швидке сканування, підсумок у консолі
.\Debloater9.ps1 -Scan -Deep                    # з winget, Windows Update, SFC
.\Debloater9.ps1 -Scan -Report C:\report.html   # зберегти HTML-звіт
.\Debloater9.ps1 -Checklist                     # чекліст з автоматичними галочками (перевіряє фактичний стан)
.\Debloater9.ps1 -Checklist -Run All -Yes       # виконати всі автоматичні кроки (без перезавантаження)
.\Debloater9.ps1 -Checklist -Run 3,5 -Yes       # лише вибрані кроки
.\Debloater9.ps1 -Checklist -Run All -AllowReboot -Yes   # разом із перезавантаженням наприкінці
.\Debloater9.ps1 -Checklist -Done 1             # позначити ручний крок виконаним
```

> Реалізовано в 0.2.0. Замість окремого `-Scan -Fix` виправлення виконуються через `-Checklist -Run` — з урахуванням порядку і залежностей кроків.

Код завершення `-Scan`: 0 — добрий стан, 1 — потребує уваги, 2 — є критичні проблеми (зручно для скриптів сервісного центру).
