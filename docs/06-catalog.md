## Профілі

| Профіль | Для кого | Правило рекомендації |
|---|---|---|
| Мінімальний | Будь-який ПК; лише безпечні зміни конфіденційності й реклами | Запасний варіант |
| Стандартний | Звичайний ПК з SSD | SSD і ≥ 8 ГБ RAM |
| Слабкий ПК | Старі ноутбуки | HDD **або** ≤ 4 ГБ RAM **або** ≤ 2 ядра |
| Ігровий | Ігрові ПК | Дискретна відеокарта і ≥ 16 ГБ RAM (лише пропозиція, не автоматично) |
| Максимальний | Досвідчені користувачі | Ніколи не рекомендується автоматично |

Експертні твіки (🔴) не входять у жоден профіль — їх вибирають лише вручну.
