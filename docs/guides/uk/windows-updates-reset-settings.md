# Оновлення Windows повернуло Copilot, рекламу чи видалені застосунки — як зберегти налаштування

*[English](../windows-updates-reset-settings.md)*

Після великого оновлення (наприклад, 24H2 → 25H2), а іноді й після накопичувальних оновлень Windows може
перевстановити вбудовані застосунки, знову ввімкнути Copilot, рекламу й «пропозиції», скинути політики й повернути
службам автоматичний запуск. Це найчастіша причина скарг «я почистив Windows, а за місяць усе повернулося».

## Чому так буває

- Велике оновлення — це новий образ Windows: застосунки, вбудовані в образ, повертаються й для наявних користувачів.
- Частина налаштувань зберігається там, що оновлення переписує (макет Пуску, ContentDeliveryManager, пакети застосунків).
- Програми на кшталт OneDrive чи Teams оновлюються самі й знову вмикають собі автозапуск.

## Що можна зробити вручну

1. Видаляйте застосунки й з образу (`Remove-AppxProvisionedPackage -Online`), а не лише для свого користувача.
2. Надавайте перевагу політикам (`HKLM\SOFTWARE\Policies\…`) замість налаштувань користувача — вони частіше
   переживають оновлення.
3. Після кожного великого оновлення перевіряйте: Параметри → Програми, Конфіденційність і захист, Персоналізація →
   Пуск, Автозавантаження.

## За допомогою Debora (автоматично)

Debora пам'ятає кожну зміну, яку ви зробили через неї (журнал змін), і порівнює її з поточним станом:

- після зміни збірки Windows Debora показує **«Windows скасувала ваші зміни: N»** зі списком — лишіть позначки на тому,
  що треба повернути, і зніміть з того, що хочете залишити як зробила Windows;
- щотижневе **автообслуговування** може повертати це без запитань;
- перевірка на «Огляді» має для цього знахідку з кнопкою «Виправити»;
- командний рядок: `Debora.exe -Guard` (перелік) і `Debora.exe -Guard -Yes` (повернути).

Повернення — теж сесія журналу, тож його можна відкотити. Якщо відкотити зміну в «Журналі змін», Debora перестає за
нею стежити.
