# 1. Бачення

## Проблема

Свіжа Windows 10/11 містить рекламні застосунки, телеметрію, фонові служби й візуальні ефекти, які на слабких ПК помітно сповільнюють роботу. Наявні інструменти мають недоліки:

- скрипти з інтернету (`irm | iex`) — «чорна скринька», без попереднього перегляду і чесного відкату;
- WinUtil потужний, але англомовний, орієнтований на досвідчених користувачів, і його відкат повертає «значення за замовчуванням», а не те, що було на конкретному ПК;
- жоден інструмент не враховує залізо: поради для ПК з SSD і 32 ГБ RAM шкідливі для ноутбука з HDD і 4 ГБ (і навпаки).

## Мета

Дати людині без технічної підготовки безпечно підготувати Windows до роботи за 5 хвилин, а досвідченому користувачу — точний контроль над кожною зміною.

## Цільова аудиторія

| Аудиторія | Що їй потрібно |
|---|---|
| Звичайний користувач зі старим ноутбуком | Одна кнопка «Рекомендовані для мого ПК», зрозумілі пояснення українською, можливість усе повернути |
| Ентузіаст / геймер | Повний перелік твіків, рівні ризику, профіль «Ігровий» |
| Сисадмін / сервісний центр | Запуск без інтерфейсу з файлом профілю на десятках ПК, журнал змін |

## Принципи

1. **Нічого не робити мовчки.** Кожна зміна видна до застосування і записана в журнал.
2. **Будь-яку зміну можна відкотити** до точного попереднього стану.
3. **Безпека важливіша за «максимальний деблоат».** Захисник Windows, оновлення безпеки, UAC, Microsoft Store не ламаються ([Безпека](07-safety.md)).
4. **Поради залежать від заліза.** Вимикати SysMain на SSD чи гібернацію на HDD — шкідливо; утиліта це знає.
5. **Дані, а не код.** Твіки — записи в JSON, які легко переглянути, перевірити й доповнити.
6. **Жодної телеметрії** з боку самої утиліти.

## Межі (що НЕ робимо)

- Не модифікуємо системні файли та образи Windows (на відміну від MicroWin у WinUtil) — принаймні до 1.0.
- Не «активуємо» Windows і не обходимо ліцензування.
- Не вимикаємо Захисник Windows і не видаляємо Microsoft Store, Edge WebView2, .NET.
- Не робимо «чистильник реєстру» — користі немає, ризик є.

## Порівняння з WinUtil

| | WinUtil | Debora |
|---|---|---|
| Мова інтерфейсу | англійська | українська + англійська |
| Рекомендації під залізо | ні (пресети Minimal/Standard/Advanced) | так: визначення HDD/SSD, RAM, CPU, батареї |
| Відкат | до «значень за замовчуванням» | до знімка стану перед зміною |
| Показ поточного стану твіка | частково | для кожного твіка: ✓ / ✗ / частково |
| Попередній перегляд змін | ні | так, по кожному ключу/службі |
| Рівні ризику | ні | безпечний / помірний / експертний |
| Встановлення програм (winget) | так | так (етап 2) |
| Керування оновленнями | так | так (етап 2) |
| Діагностика (SMART, автозавантаження, пам'ять) | частково | так, окрема вкладка |
| Створення ISO (MicroWin) | так | ні (поза межами 1.0) |
