# 5. Інтерфейс

## Структура вікна

Ліва навігація з вкладками, праворуч — вміст. Унизу — смуга стану: вибрано N змін, потрібне перезавантаження, кнопка «Застосувати».

| Вкладка | Призначення | Етап |
|---|---|---|
| **Огляд** | Результат [сканера](12-scan.md): оцінка, знахідки з кнопками «Виправити», залізо, рекомендований профіль | MVP |
| **Чекліст** | Покроковий план після сканування: що робити, де взяти, що встановити; автоматичні галочки, прогрес між запусками | MVP |
| **Твіки** | Усі твіки за категоріями, стан, ризик, профілі | MVP |
| **Застосунки** | Вбудовані Appx: встановлені, «безпечно видалити», видалення | MVP |
| **Встановлення** | Каталог програм через winget | 2 |
| **Обслуговування** | Очищення, автозавантаження, SFC/DISM, оновлення Windows | 2 |
| **Драйвери** | Проблемні пристрої, оновлення з Windows Update, сторінка виробника ([докладно](11-drivers.md)) | 3 |
| **Журнал** | Сесії змін, перегляд, відкат | MVP |
| **Налаштування** | Мова, тема, точка відновлення, перевірка оновлень утиліти | MVP |

## Твіки

```
┌ Профіль: [Слабкий ПК ▾]   Пошук: [__________]   Ризик: [усі ▾] ──────┐
│                                                                      │
│ Конфіденційність                                       5 з 6 вибрано │
│  [x] Вимкнути телеметрію                      безпечно   ✓ застос.   │
│  [x] Вимкнути рекламу та поради               безпечно   ✗           │
│  [ ] Вимкнути службу геолокації               помірно    ✗           │
│ Продуктивність                                                       │
│  [x] Вимкнути SysMain (для HDD)               помірно    ✗           │
│  [-] Вимкнути гібернацію   недоступно: на HDD сповільнить запуск     │
│ ...                                                                  │
│ ▸ Деталі: що саме зміниться (розгортається по кліку на твік)         │
│   HKLM\...\DataCollection  AllowTelemetry   1 → 0                    │
│   Служба DiagTrack         Automatic → Disabled                      │
└──────────────────────────────────────────────────────────────────────┘
  Вибрано 18 змін · 2 потребують перезавантаження     [ Застосувати ]
```

- Ризик кольором: безпечно — зелений, помірно — жовтий, експертний — червоний.
- Експертні твіки приховані, доки не ввімкнено «Показувати експертні» в налаштуваннях.
- Непридатні твіки видно сірим з причиною — користувач розуміє, чому їх немає.

## Застосування

1. «Застосувати» → діалог **Попередній перегляд**: таблиця всіх змін (що → було → стане), кількість видалених застосунків, попередження про перезавантаження.
2. Підтвердження → екран прогресу: смуга, поточна дія, живий журнал, кнопка «Скасувати» (зупиняється після поточної дії).
3. Підсумок: успішно / пропущено (вже застосовано) / помилки з причинами; кнопки «Перезавантажити» і «Відкрити журнал».

## Журнал

Список сесій (дата, профіль, кількість змін, результат). Сесія розгортається до записів; кнопки «Відкотити сесію» та «Відкотити вибране». Перед відкатом — той самий попередній перегляд.

## Правила UX

- Кожен елемент має підказку: що робить, кому варто, кому не варто.
- Жодних дій без підтвердження, що змінюють систему.
- Довгі операції — тільки у фоні; вікно завжди відповідає.
- Тексти короткі, без жаргону; технічні деталі — у розгортанні «Деталі».
- Шрифт Segoe UI, мінімум 12 px; контраст WCAG AA; повна робота з клавіатури.
- Тема — світла/темна за системною (`AppsUseLightTheme`), з перемикачем.
