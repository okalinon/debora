# Що зробити після чистого встановлення Windows 11 або 10

*[English](../setup-windows-11-after-clean-install.md)*

Перелік дій для щойно встановленої Windows — у такому порядку, щоб нічого не робити двічі.

## Перелік

1. **Спершу драйвер мережі.** Якщо інтернету немає, встановіть драйвер мережевої карти чи Wi-Fi із сайту виробника
   ПК/ноутбука (завантажте на флешку з іншого комп'ютера).
2. **Драйвери.** Windows Update ставить базові драйвери; для відеокарти, чипсета й звуку краще пакети виробника ПК
   або чипа (Intel, AMD, NVIDIA).
3. **Оновлення Windows** — доки нічого не лишиться; часто це 2–3 раунди з перезавантаженнями.
4. **Деблоат і приватність.** Приберіть попередньо встановлені застосунки, вимкніть рекламу, телеметрію й Copilot, якщо
   ним не користуєтесь (див. [Непотрібні застосунки](remove-bloatware-windows-11.md),
   [Телеметрія й реклама](disable-telemetry-windows-11.md), [Copilot](disable-copilot-windows-11.md)).
5. **Програми.** Ставте через winget замість завантаження інсталяторів по одному:
   `winget install Google.Chrome 7zip.7zip VideoLAN.VLC` (без вбудованих панелей і реклами).
6. **Захист.** Переконайтеся, що захист системи (точки відновлення) увімкнено, а «Безпека Windows» активна.
7. **Точка відновлення / резервна копія**, коли все працює.

## За допомогою Debora — за один прохід

Вкладка **«З нуля»** виконує кроки 2–7 за один запуск:

- драйвери з каталогу Microsoft Update і Windows Update (лише точні збіги для вашого заліза);
- деблоат вибраного рівня («Обережно / Рекомендовано / Максимально»);
- набір налаштувань під цей ПК (SSD/HDD, пам'ять, ноутбук чи настільний);
- програми з наборів (Базовий набір, Навчання й робота, Ігри, Творчість, Розробка…) або власний список;
- оновлення Windows — **якщо вони потребують перезавантаження, ПК перезавантажиться, а після входу налаштування
  продовжиться саме**;
- підсумкова перевірка стану, що виправляє знайдене.

План зберігається у файл і переноситься на інші ПК. Вкладка **«Перевстановлення»** покладе план на флешку з Windows:
Windows встановиться без запитань, отримає драйвери цього ПК і після першого входу виконає план.

Командний рядок: `Debora.exe -Setup -ProfilePath plan.json -WhatIf` покаже план.
