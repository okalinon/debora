# 17. План розвитку після 0.39 (2026-10-13)

Напрям, обраний 2026-10-11: **сильний безкоштовний інструмент** — глибокий деблоат і налаштування ПК з нуля.
Бізнес-версія для кількох ПК — пізніше (формати профілів і звітів тримаємо переносними).

## A. Глибший деблоат

| # | Що | Навіщо | Обсяг |
|---|---|---|---|
| A1 ✅ 0.40.0 | **Варта після оновлень Windows.** Debora пам'ятає, що прибрано (журнал), і після кожного оновлення Windows (номер збірки змінився) або раз на тиждень за розкладом перевіряє, чи не повернулось: Copilot, реклама, застосунки, політики, служби. Робить деблоат постійним. | середній |
| A2 | **Розширений каталог** (з поясненням «що зміниться для вас» і відкатом для кожного пункту): реклама й «рекомендації» в Параметрах, Пуску, екрані блокування, Провіднику; Edge (бічна панель, покупки, винагороди, запуск у фоні, «найкраще для вас»); Phone Link, Windows Backup-нагадування, пропозиції Microsoft 365/OneDrive; приватність до рівня O&O ShutUp10 (≈+40 пунктів: рекламний ID, рукописний ввід, доступ застосунків до контактів/календаря/мікрофона, синхронізація буфера, хмарний вміст); нові ШІ-функції (Photos, Snipping Tool, Copilot у Провіднику). | Глибина — головна цінність Debora. | великий, кроками |

| A4 | **Бруд виробників ноутбуків/ПК** (HP, Dell, Lenovo, ASUS Armoury/MyASUS, Acer Care, MSI Center): застосунки, служби, завдання, автозапуск — за виробником з `SystemInfo`. | На нових ноутбуках це половина «сміття». | середній |

## B. Налаштування з нуля

| # | Що | Навіщо | Обсяг |
|---|---|---|---|
| B1 | **Продовження після перезавантаження**: майстер записує стан, ставить себе на один запуск після входу і йде далі (драйвери → перезавантаження → оновлення → перезавантаження → решта). | Зараз «один прохід» рветься на першому ж перезавантаженні. | середній |
| B2 | **«Перенести з цього ПК»**: профіль зі стану поточного ПК — програми (winget/GitHub), застосовані налаштування й деблоат, схема живлення; за згодою — профілі Wi-Fi. На новому ПК — той самий майстер. | Найприродніший сценарій: новий ноутбук «як старий, але чистий». | середній |
| B3 | **Вибір окремих пунктів деблоату в плані майстра** (зараз — лише «рекомендоване»). | Профіль точно відтворює вибір людини. | малий |
| B4 | **Чиста флешка**: деблоат самого образу Windows на флешці (DISM: прибрати вбудовані застосунки й задати політики офлайн) — Windows встановлюється вже без сміття. Лише за явною згодою, з копією `install.wim`. | Найглибший «з нуля»; поєднує деблоат і перевстановлення. | великий |

## C. Перевірка наживо (паралельно, потрібен запуск від адміністратора)

Ще не виконувались наживо: кнопки «Виправити» в знахідках, майстер «З нуля», встановлення драйверів і відкат, відкат сесії, видалення гри Steam. Для B1/B4 потрібна віртуальна машина (Windows Home не має Sandbox/Hyper-V → VirtualBox з ознайомчою Windows 11).

## D. Реліз 1.0 (окремий трек)

Репозиторій на GitHub, самооновлення, `Debora.exe`, підпис (SignPath), changelog, англійська сторінка.

## Рекомендований порядок

1. **A1 Варта після оновлень** — найбільша користь за помірний обсяг; спирається на вже наявний журнал.
2. **A3 + A2** (рівні, потім каталог розділ за розділом, кожен — окремий реліз з тестом «без дублів»).
3. **B1 → B3 → B2** — майстер стає справді «одним проходом».
4. **A4, A5**, далі **B4** (після перевірки майстра на ВМ).
