# 7. Безпека й відкат

## Рівні захисту

1. **Точка відновлення** перед першою зміною кожної сесії. Windows дозволяє одну точку на 24 години — тимчасово ставимо `SystemRestorePointCreationFrequency = 0`, потім повертаємо. Якщо захист системи вимкнено, пропонуємо ввімкнути; якщо створити не вдалося, показуємо попередження і просимо явне підтвердження.
2. **Знімок стану** кожної дії в журналі сесії ([Модель твіків](04-tweak-model.md#знімок-і-журнал)).
3. **Резервна копія реєстру**: ключі, яких торкається сесія, експортуються в `%ProgramData%\Debloater9\sessions\<id>\backup.reg`.
4. **Попередній перегляд** і підтвердження перед кожним застосуванням і відкатом.

## Що утиліта ніколи не робить

| Не чіпаємо | Чому |
|---|---|
| Захисник Windows, SmartScreen, брандмауер | Головний захист на ПК без стороннього антивіруса |
| Оновлення безпеки (повне вимкнення Windows Update) | Пауза до 35 днів — так; вимкнення назавжди — ні |
| UAC | Захист від тихого підвищення прав |
| Microsoft Store, App Installer (winget), WebView2, .NET, VC++ | Без них ламаються інші програми та відновлення застосунків |
| Калькулятор, Фото, Блокнот, Медіаплеєр Windows 11 | Користувачі очікують їх; заміна не очевидна |
| Файл підкачки (вимкнення) | На 4–8 ГБ RAM призводить до збоїв програм |
| «Чистка реєстру» | Немає користі, є ризик |
| Системні файли й образи (`takeown` на System32 тощо) | Ламає оновлення й SFC |

## Правила для твіків

- `command` — лише коли немає типізованої дії, і завжди з `undoRun`; рев'ю коду обов'язкове.
- Твіки, що вимикають функцію, якою людина може користуватися (OneDrive, геолокація, Xbox), — не нижче 🟡 і з поясненням, що перестане працювати.
- Твіки з реальним ризиком для стабільності чи безпеки (HVCI, вимкнення Spectre-захисту) — 🔴, приховані за замовчуванням, з окремим попередженням.
- Залежні від заліза твіки мають `requires.hardware`: не можна вимкнути SysMain на SSD «випадково».

## Відкат

- **Сесія повністю** — записи у зворотному порядку.
- **Окремі твіки** — лише записи цього твіка.
- **Конфлікт:** якщо значення змінилося після нас, запис пропускається з поясненням (не затираємо чужі зміни).
- **Видалені застосунки** — повертаються через winget (`9WZDNCRFJ…` id Store) або посиланням на Store; якщо пакет недоступний — показуємо, що повернути не вдалося.
- **Останній рубіж** — точка відновлення системи (кнопка «Відкрити відновлення системи» в Журналі).

## Цілісність утиліти

- Релізи підписуються Authenticode через SignPath Foundation (з релізу 1.0); до того й надалі поруч лежить `SHA256SUMS`.
- Утиліта не завантажує й не виконує код з інтернету під час роботи. Мережа: winget (за дією користувача) і перевірка нової версії (за згодою, лише читання номера версії).
- Жодної телеметрії, аналітики чи «анонімної статистики».
